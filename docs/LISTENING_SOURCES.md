# الاستماع في تطبيق فذكر

المصدر الرسمي: [MP3Quran API v3](https://www.mp3quran.net/ar/api).

| البيانات | المسار | الاستخدام |
| --- | --- | --- |
| القراء والمصاحف والسور | `/api/v3/reciters?language=ar` | قائمة القارئ، `moshaf.server` و`surah_list` |
| الإذاعات | `/api/v3/radios?language=ar` | مزامنة محطات `app.stations` الحالية؛ تحديث رابط البث بالمعرّف الخارجي بعد فشل التشغيل |
| التلفزيون المباشر | `/api/v3/live-tv?language=ar` | جلب HLS الرسمي وتجديده قبل فتح المشغّل |

الكتالوج المركزي في Supabase هو المصدر المعتمد للمحطات والهوية المنسّقة.
تستهلك `ReciterCatalogService` الواجهة الرسمية لإكمال المصاحف والسور؛
تربط الاسم المنظّم بهوية القارئ الحالية عندما يتطابق. لا تخزن أي مفتاح سري
في Flutter. تظل واجهة Quran Foundation الحالية مصدر الآيات والصوت الدقيق
حيثما يدعمه قارئ القرآن القائم.

## التخزين والتحديث

- `fadhkur_listen_metadata.db` (SQLite/sqflite): كاش قوائم القراء والتلاوات،
  مع وقت تحديث؛ مدته 24 ساعة. تحفظ الإذاعات في الكاش الحالي بحد أقصى 7 أيام.
- التلاوات المحمّلة: `ApplicationDocuments/quran/recitations/{reciter}/{moshaf}/surah_001.mp3`.
  الملف `.part` لا يصبح قابلاً للتشغيل قبل اكتماله. لا تضاف الوسائط إلى APK أو SQLite.
- يُبنى رابط السورة بعد التحقق من رقمها داخل `surah_list` ومن نطاق خادم
  MP3Quran، ثم إضافة رقمها بثلاث خانات و`.mp3`.
- عند انقطاع الشبكة تظهر بيانات القراء المحفوظة وتعمل ملفات السور المحلية؛
  الإذاعات والقنوات تحتاج اتصالًا. البث له محاولة واحدة بالرابط الرسمي
  المحدث بعد فشل المشغّل، دون حلقة إعادة اتصال مفتوحة.
- التنزيل الحالي أثناء فتح التطبيق؛ لا يوجد ادعاء بأنه يستمر بعد قتل العملية.
  مدير التنزيل الموجود للآيات له طابور واستعادة عبر WorkManager.

## حدود الحقوق والوظائف

يعرض التطبيق نسبة المصدر و[توثيق API](https://www.mp3quran.net/ar/api) في
«المصادر وعن التطبيق». السماح بعرض روابط API لا يثبت إذن تسجيل بث إذاعي أو
مرئي أو إعادة استضافته. لا يظهر زر تسجيل حتى تتوفر موافقة موثقة لهذا الاستخدام.
القناتان اليدويتان القديمتان في `app.video_channels` موسومتان بـ
`user_configured`/`YouTube` ولا تُعرضان في كتالوج البث المباشر الجديد.

الأعمال المتبقية: طابور تنزيل المصاحف في خدمة خلفية مع تقدم وإيقاف واستئناف؛
تسجيل البث بعد توثيق الإذن؛ وإدارة حالة القنوات الرسمية في Supabase بدلاً من
الاعتماد على كاش الهاتف وحده. لا يُسمّى أي إصدار يتضمن هذه المرحلة مكتملًا
لهذه الوظائف قبل اختبارها على جهاز Android 8 وجهاز حديث.
