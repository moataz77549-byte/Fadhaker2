# مصادر بث إضافية للمراجعة

تاريخ المراجعة: 2026-09-26. هذه روابط المؤسسات الأصلية، وليست روابط ملفات
بث مثبتة أو موافقات لإعادة نشر الصوت. يُدخل كل مرشح إلى لوحة الإدارة بحالة
`REVIEW_REQUIRED` و`production_enabled=false` حتى تمر مراجعة المصدر والصوت
وشروط التضمين. لا تضف رابطًا مؤقتًا مستخرجًا من مشغل الويب إلى Flutter.

مصدر MP3Quran API v3 موجود بالفعل في `provider-sync` و`app.stations`؛ لا
تستورد محطة منه مرة ثانية إذا كان رابط البث نفسه محفوظًا. Quran Foundation
وAlQuran.cloud يوفران تلاوات حسب الطلب، ولا تُعرض ملفاتهما كإذاعة حية.

## خطوات تفعيل مصدر

1. سجل المالك والرابط الرسمي الثابت، وشروط التضمين والنسبة، ومعرف المحطة.
2. اختبر رابط HTTPS بعد إعادة التوجيه من شبكة هاتف فعلية: الاستجابة الصوتية،
   بدء التشغيل، الانقطاع، وصيغة MP3/AAC/HLS.
3. أدخل المزود والمحطة في `app.content_providers` و`app.stations` بحالة مراجعة؛
   نفذ فحص الصحة الموجود، وتحقق من عدم تكرار الرابط مع MP3Quran.
4. بعد اعتماد الحقوق والصحة من الإدارة، فعّل المحطة مع attribution ورابط
   بديل موثق إن توفر. راقب الأخطاء على Android 8 وAndroid حديث.

لا تُنشر محطة مشغّلها الأصلي يعتمد على رابط مؤقت حتى يتوفر تكامل رسمي
قابل للتجديد. ولا تسجل بث الغير أو تعيد استضافته بلا تصريح مستقل.
