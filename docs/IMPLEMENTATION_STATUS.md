# حالة تنفيذ فذكر

## ما تم إنجازه

تم فحص مستودع `Mtzallqmy/Fadhkur` وربطه بمشروع Supabase `ttvasynaxkkcwrmvlorg` وبمشروع Firebase `fadhkur-2f78c`. تم ضبط تطبيق Android باسم الحزمة `app.fadhkur` واسم العرض العربي `فذكر`، وإضافة Workflow لإصدار APK ARM64 يستهدف Android 8 وما بعده مع توقيع GitHub Actions.

تمت إضافة تهيئة Supabase الآمنة، وربط خدمة Firebase Messaging بطلب موافقة المستخدم وتسجيل installation في Supabase، وإضافة جدولة إشعارات محلية للأذكار. كما تمت إزالة روابط الصوت الوهمية من المسارات الرئيسية وربط تشغيل الإذاعات بكتالوج MP3Quran، وربط تشغيل التلاوات بروابط MP3Quran، وإضافة تنزيل تلاوات فعلي إلى التخزين المحلي مع تقدم وحالة فشل وتشغيل دون اتصال.

تمت إضافة خدمات الكاش والمزامنة والتسجيل والتذكيرات، وإصلاح مزوّد قوائم التشغيل واختبارات الإقلاع والمفضلة، وإضافة هوية بصرية جديدة: أيقونة Android وشعار عربي باسم `فذكر` بألوان كحلي وفيروزي وذهبي.

## ما تم التحقق منه

نجح `flutter analyze` واختبارات Flutter في Workflow رقم `35671804670`. فشل البناء اللاحق في مرحلة Flutter kernel snapshot بسبب عدم توافق `record_linux-0.7.2` مع `record_platform_interface-1.6.0`. تم إضافة تثبيت `record_android: 1.3.1` ثم اكتُشف أن واجهة المنصة ما زالت تُحل إلى 1.6.0؛ لذلك أُضيف تثبيت `record_platform_interface: 1.1.0`، ويجب تشغيل Workflow جديد للتحقق النهائي.

## المتبقي قبل إعلان الجاهزية

1. نجاح `flutter analyze` والاختبارات والبناء الموقّع بعد تثبيت إصدارات record المتوافقة.
2. التحقق من أن APK يحتوي الأيقونة الجديدة فعليًا وأن اسم التطبيق يظهر `فذكر`.
3. اختبار FCM على جهاز Android فعلي: طلب الإذن، تسجيل token، استقبال foreground/background، وإلغاء الاشتراك.
4. اختبار تنزيل سورة كاملة، إيقاف واستكمال التنزيل، فحص SHA-256، التشغيل دون شبكة، وحذف الملف.
5. اختبار التشغيل الصوتي في الخلفية وسلوك السماعة/قفل الشاشة؛ لا يُعد ذلك مثبتًا من CI وحده.
6. مراجعة جداول Supabase وRLS من لوحة المشروع بعد أي تغيير في schema، واختبار لوحة الإدارة بحساب مدير منفصل.
7. تدوير كلمة مرور Google وGitHub PAT اللذين أُرسلا في المحادثة قبل أي استخدام خارجي.
8. إنشاء GitHub Release رسمي جديد فقط بعد نجاح البناء النهائي؛ لا ينبغي اعتبار الإصدارات السابقة صالحة للتسليم.
