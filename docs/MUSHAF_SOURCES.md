# مصادر المصحف والقارئ الموحد

آخر تحديث: **2026-09-26**.

هذا المستند يصف المسار الجديد لقارئ القرآن في Fadhkur، مع إبقاء توثيق
النظام المصوّر السابق للرجوع المؤقت أثناء فترة التحقق.

## 1) المسار الأساسي الجديد

### Quran Foundation / Quran.com

يظل `QF_CLIENT_ID` و`QF_CLIENT_SECRET` داخل Supabase Edge Function
`quran-yutla-api` فقط، ولا يدخلان APK أو BuildConfig أو assets.

الموارد المستخدمة:

- `/verses/by_page/{page}` مع `mushaf=1` (QCF V2) للصفحات 1–604.
- `words=true` وحقول `verse_key,location,line_number,text_qpc_hafs,code_v2`
  لبناء تخطيط الصفحة بدون 604 صورة.
- `text_uthmani` للنص العثماني.
- `text_uthmani_tajweed` للتجويد الدلالي؛ الوسوم تُفسر للعرض فقط ولا
  تغيّر النص المصدر.
- `/pages/lookup?from={verseKey}&to={verseKey}&mushaf=1` لربط الآية
  بالصفحة.
- Search API خلف Edge Function للبحث النصي والتنقلي.
- `/resources/recitations` و`/recitations/{id}/by_ayah/{verseKey}`
  لتلاوة الآية، مع تشغيل القوائم من الآية عبر مشغل الصوت الموحد الموجود.

لا يتم تنزيل خطوط QCF للصفحات الـ604. يستخدم الوضع المدني بيانات الأسطر
والكلمات مع QPC Hafs/Unicode الموثوق، وهو أخف وأفضل توافقًا مع Android 8.

## 2) المصحف الموضوعي — Quranpedia

المصدر: `https://api.quranpedia.net/v1/topics`.

- البيانات موضوعات هرمية: `id`, `name`, `parent_id`, `ayahs`.
- لا نخزن نسخة ثانية من نص القرآن.
- التخزين المحلي SQLite:
  - `topic`
  - `verse_topic`
  - `topic_source`
- أول مزامنة تُخزّن الموضوعات محليًا.
- التشغيل اللاحق يستخدم البيانات المحلية ويتحقق دوريًا عبر
  `/v1/changes?since=YYYY-MM-DD`.
- ملف `topics-index.json.gz` الرسمي حجمه قرابة **159 KB**؛ لا يتم تضمينه
  في APK حاليًا، لأن المسار المعتمد هو مزامنة API ثم التخزين المحلي.
- إصدار ملفات Quranpedia الرسمي وقت التكامل: **2026-09-24**.
- سياسة المصدر تسمح باستخدام API داخل التطبيقات دون اشتراط الإسناد،
  لكن Fadhkur يعرض الإسناد صراحة في صفحة «المصادر وعن التطبيق».
- التصنيف الموضوعي محتوى فهرسي/تفسيري وليس جزءًا من نص القرآن.

## 3) التخزين والكاش

- صفحات النص/التخطيط: `sqflite` في `fadhkur_mushaf.db`.
- حد الكاش: آخر **180** صفحة قابلة لإعادة الجلب (LRU تقريبي حسب
  `updated_at`).
- الذاكرة: الصفحة الحالية مع prefetch محدود للسابقة والتالية، وتُزال
  Futures البعيدة عن نافذة ±2 صفحات.
- الموضوعات: `fadhkur_quran_topics.db`.
- الإعدادات والموضع الأخير: `shared_preferences`.
- `QuranLocation` يحفظ الصفحة + السورة + الآية + `verseKey`.
- العلامات وبيانات المستخدم لا تدخل في eviction ولا تُحذف في migration.

## 4) النظام المصوّر السابق — مسار رجوع فقط

الـ renderer القديم للصور ما يزال موجودًا مؤقتًا خلف:
`QURAN_LEGACY_IMAGE_RENDERER=false`.

والـ renderer النصي القديم خلف:
`QURAN_LEGACY_TEXT_RENDERER=false`.

لا يُفعّلان افتراضيًا. لن تُحذف الملفات/المسارات القديمة قبل نجاح
الاختبارات والبناء والتحقق الفعلي من الأوضاع الأربعة.

## 1) إصدارات المصحف المصوّر (604 صفحات — المصحف المدني)

بتخطيط **604 صفحات** فقط. أي مصدر بعدد صفحات مختلف لا يُعتمد (قاعدة صارمة

## 2) الخطوط (تحميل عند أول استخدام + تخزين على القرص)

لا تُضمَّن ملفات الخطوط في حزمة التطبيق. عند أول اختيار لخطٍّ له رابط موثّق
يُنزَّل الملف ويُحفظ في مجلد دعم التطبيق (`quran_fonts/<id>.ttf`) ثم يُسجَّل
عبر `FontLoader`. لا تُنزَّل الخطوط الأربعة عند بدء التطبيق. عند أي فشل —
أو غياب الرابط — يُستخدم **خط النظام** (fallback) مع ملاحظة صادقة في
الإعدادات، وحدّ أدنى 50KB لحجم الملف يحمي من تخزين صفحات خطأ HTML كخط.

### أ) `uthmanic-hafs` — QPC Hafs font (موثّق ✓)

- الرابط: `https://static-cdn.tarteel.ai/qul/fonts/UthmanicHafs_V22.ttf`
- التحقق الحي 2026-09-23: **HTTP 200**، ‏`Content-Type: font/ttf`،
  ‏`Content-Length: 297,700` بايت.
- المصدر: صفحة خط «QPC Hafs font» في مكتبة QUL:
  `https://qul.tarteel.ai/resources/font/245` (الرابط أعلاه هو رابط
  التحميل المباشر المعروض فيها).
- شروط KFGQPC المنقولة في نتائج البحث: استخدام ونسخ وتوزيع مجاني مع
  الإسناد، مع منع التعديل أو إعادة البرمجة أو البيع — تُذكر كإشعار منشور
  لا كترخيص مفتوح عام.

### ب) `kfgqpc-hafs` — KFGQPC Uthmanic Hafs (إصدار 1.8) (موثّق ✓)

- الرابط: `https://cdn.jsdelivr.net/gh/mohammed-2-5/islamic-library-data@master/fonts/UthmanicHafs_v18.ttf`
- التحقق الحي 2026-09-23: **HTTP 200**، ‏`font/ttf`؛ الحجم عبر المصدر
  الخام 242,368 بايت.
- ملاحظة: الموقع الرسمي `fonts.qurancomplex.gov.sa` **لم يستجب** من شبكة
  الفحص (انتهت المهلة بعد CONNECT)، فتعذّر التحقق من رابطه المباشر.

### ج) `qcf` — تعذّر التحقق (لا ملف نصي واحد)

لا يوجد ملف QCF نصي واحد موثّق يصلح خطًّا عامًا لوضع النص:
- خطوط QCF في منظومة Quran Foundation هي خطوط glyphs **ملفٌ لكل صفحة**
  (`QCF_P001.TTF` … `QCF_P604.TTF` — 604 ملفات لنقاط PUA خاصة)، ولا تصلح
  خطًّا Unicode عامًا لعرض نص الآيات.
- `QCF_BSML.TTF` خط بسملة فقط.
- النتيجة: الخيار يبقى في السجل (قابل للتجاوز من الـ Backend) **بلا رابط
  تحميل**، ويُعرض النص بخط النظام مع ملاحظة صادقة.

### د) `uthmanic-vector` — تعذّر التحقق (لا مصدر)

لم يُعثر على خط موثّق بهذا الاسم في أي مصدر مفتوح (بحثان مستقلان بصيغ
مختلفة). الخيار يبقى في السجل بلا رابط تحميل، ويُستخدم خط النظام مع
ملاحظة صادقة.

## 3) ملاحظات تشغيلية

- **الصور**: `CachedNetworkImage` (تخزين قرص + ذاكرة)، بناء كسول عبر
  `PageView.builder` — لا تُحمَّل الصفحات الـ 604 في الذاكرة، ولا يوجد
  prefetch جماعي.
- **الخطوط**: `QuranFontLoader.ensureLoaded` — تنزيل مرة واحدة عند أول
  اختيار، كتابة ذرّية على القرص، دمج الطلبات المتزامنة.
- **الـ Backend يطغى**: مفاتيح `app.app_config` العامة
  (`quran.mushaf_editions`، `quran.font_options`) تُدمج فوق القيم المضمّنة؛
  القيم المضمّنة هنا احتياط عند غياب/فشل الـ Backend.
- **لا أسرار** في أيٍّ مما سبق — كلها روابط عامة.
