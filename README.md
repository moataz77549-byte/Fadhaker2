# فذكر — Fadhkur

منصة القرآن الكريم السيادية والبث الإذاعي الصوتي المدار على مدار الساعة.

**الإصدار الحالي:** `1.0.64` (build `64`) · `minSdk 26` (Android 8+) · التطبيق: `apps/mobile` (Flutter) · لوحة الإدارة: `apps/admin` (Next.js)

---

## 🌟 نظرة عامة
**«فذكر»** هو تطبيق إسلامي مستقل تم بناؤه بأعلى معايير البرمجيات السيادية، خالي تماماً من أي إعلانات أو أدوات تتبع للمستخدمين (Zero Surveillance). يوفر التطبيق تجربة عربية أصيلة (RTL-First) بالغة السلاسة، مع اعتماد تام على مجمع الملك فهد لطباعة المصحف الشريف بالمدينة المنورة ومطابقة هندسية لمعايير الصوت العالمية EBU R128 (-16.0 LUFS).

## 🚀 التشغيل والفحص المحلي السريع

### 1. فحص سلامة نصوص القرآن الكريم (Fail-Closed Gate)
```bash
./scripts/validate-checksums.sh
```

### 2. تشغيل لوحة الإدارة (Next.js)
```bash
cd apps/admin
npm install
npm run dev
```

### 3. تشغيل خدمات معالجة الصوت ومحرك الإذاعة
```bash
cd services/audio-worker && npm install && npm run start
cd services/radio-engine && npm install && npm run start
```

## ✨ الميزات
- **القرآن الكريم**: 4 روايات (حفص/ورش/قالون/الدوري)، مصحف مدني 604 صفحات بنسختين (عادية وملوّنة بالتجويد — مصادر مُتحقق منها في `docs/MUSHAF_SOURCES.md`)، 4 خطوط عثمانية مع تحميل وكاش على القرص، وضع النص، التفاسير الأربعة من الخادم، الفواصل، وآخر قراءة مع مزامنة محلية.
- **المسبحة الإلكترونية**: عدّادات متعددة، اهتزاز، وحفظ التقدم — تعمل offline بالكامل.
- **أسماء الله الحسنى (99)**: بيانات مدمجة مع شرح مختصر، بحث فوري، ومفضلة.
- **حديث اليوم**: الأربعون النووية بتناوب يومي.
- **متتبع الختمة**: خطة 30 جزءاً مبنية على تقدم القراءة.
- **التاريخ الهجري** (تقريبي، offline) بجانب الميلادي، **مواقيت الصلاة** بحساب محلي دون مشاركة الموقع.
- **الراديو المدار**: محطات من Supabase مع failover تلقائي، **مؤقت النوم** وسرعة التشغيل.
- **قنوات الفيديو**: HLS/يوتيوب ديناميكية من لوحة الإدارة.
- **الإشعارات**: FCM opt-in (11 topic)، مركز إشعارات في الإدارة عبر Edge Function، وجدولة الحملات عبر `campaign-dispatcher` + pg_cron.
- **Force Update**: فحص `min_supported_version` من `app_config` عند الإقلاع دون حجب عند تعذّر الشبكة.
- **روابط عميقة**: `fadhkur://` على مستوى النظام + allowlist صارمة للمسارات.
